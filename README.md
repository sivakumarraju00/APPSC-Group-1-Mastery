# APPSC Group-II Mastery 2.0 — Mobile-first website

## What's included
- Responsive Android/mobile-first interface plus desktop layout.
- English/Telugu interface toggle and bilingual explanations.
- 150 original practice MCQs across the five broad screening-test areas.
- Topic-wise filtering and instant feedback with explanations.
- Full 150-question mock examination, 150-minute timer, one-third negative marking, review navigation and answer review.
- Bookmarks, mistake revision, subject-wise performance and current-affairs journal.
- Dark mode, offline caching after first successful load, installable PWA manifest.
- Local browser storage; no server/database/login required.

## Run locally
Open `index.html` in a browser. For PWA installation and service-worker offline caching, serve the folder over HTTPS or localhost.

## Publish free with GitHub Pages
1. Create a GitHub repository, e.g. `appsc-group2-mastery`.
2. Upload every file in this folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)` → Save.
5. Open the published HTTPS URL on Android Chrome.
6. Chrome menu → Add to Home screen / Install app.

## Important content note
The 150 questions in this release are original practice questions, not official APPSC previous-year questions. The notes and syllabus map are a study aid. Verify the final detailed syllabus and examination scheme against APPSC Notification No.37/2026 and its annexures. Current affairs are not automatically fetched or updated; add and verify daily items from official sources.

Progress is saved in the browser's localStorage on the device and is not synchronised across devices. Clearing browser site data will remove local progress.
